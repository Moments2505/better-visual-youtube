# Install Better visual Youtube

For Microsoft Edge and Google Chrome on desktop.

## First installation

1. Download the extension ZIP from [Releases](https://github.com/Moments2505/better-visual-youtube/releases).
2. Extract it into a folder you will keep on your computer.
3. Open `edge://extensions` in Edge or `chrome://extensions` in Chrome.
4. Turn on **Developer mode**, select **Load unpacked**, and choose the folder containing `manifest.json`.
5. Reload YouTube. Open **Better visual Youtube** from the browser's extensions menu to adjust the look.

Keep the extracted folder in place while you use the extension. You can pin the extension for quick access to its settings.

## Updates and preferences

Replace the files in the same folder with the new release, click **Reload** on the extensions page, and reload YouTube. This keeps your saved preferences.

Settings are stored in your browser. **Reset to Defaults** restores the included configuration; settings do not automatically transfer to another computer.
