## Stationary panels, independent Ambient Light

- Disabling **Motion effects** now keeps Ambient Light running. Panel movement, hover magnification and hover-driven column stacking stop together; static glass is retained.
- Seek and volume hover use a lighter backdrop, and video-to-CPU tint sampling pauses while those controls are in use.
- Saved preferences are retained. Re-enabling Motion restores the saved hover choice.
- Chip text uses a lighter, static glass backdrop to address flickering/split letters when scrolling to the page top; unused chip lens maps are no longer generated.
- Added optional **Time-of-day background** for Home and Search only, with Auto, Morning, Day, Sunset, Night and intensity controls. It is off by default; Motion off retains a still sky.

Download **Better-visual-Youtube-0.4.59.zip**, replace the files in the existing extension folder, reload the extension, then reload YouTube.

This is a beta.

## Panel đứng yên, Ambient Light hoạt động riêng

- Tắt **Motion effects** vẫn giữ Ambient Light. Chuyển động panel, phóng đại hover và đổi thứ tự lớp cột theo hover cùng dừng lại; giữ nguyên kính tĩnh.
- Giảm tải lớp nền kính khi hover thanh tua/âm lượng, tạm ngưng đọc màu video về CPU trong lúc tương tác.
- Giữ cài đặt đã lưu. Bật lại Motion sẽ khôi phục lựa chọn hover trước đó.
- Dùng lớp nền kính tĩnh nhẹ hơn cho chip để xử lý chữ tách đôi/nhấp nháy khi cuộn lên đầu trang; bỏ tạo map kính không còn dùng cho chip.
- Thêm **Time-of-day background** chỉ ở Trang chủ và Tìm kiếm, gồm Auto, Morning, Day, Sunset, Night và độ đậm. Mặc định tắt; tắt Motion vẫn giữ bầu trời tĩnh.

Tải **Better-visual-Youtube-0.4.59.zip**, thay tệp trong thư mục extension đang dùng, tải lại extension rồi tải lại YouTube.

Đây vẫn là bản beta.
