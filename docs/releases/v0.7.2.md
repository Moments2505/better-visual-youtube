Better Visual for YouTube 0.7.2 updates the extension identity for Chrome Web Store trademark compliance, adopts your curated personal Edge defaults out of the box, aligns the Privacy Policy with `chrome.storage.sync`, removes the upstream Google Form URL, and adds a complete Chrome Web Store listing kit.

## Highlights

- **Extension Rename & Clean Upstream Bundle (`manifest.json`, `_locales/*/messages.json`, `src/popup/popup.html`, `src/background/service-worker.js`, `vendor/ambient/content-main.js`)**: Renamed the extension display identity from *Better visual Youtube* to **Better Visual for YouTube** (`short_name: "Better Visual"`) to meet Chrome Web Store branding guidelines, and replaced the inherited upstream Google Form feedback URL helper (`getFeedbackFormLink()`) with a clean direct link to the repository's GitHub Issues page.
- **Privacy Policy Synchronization & Public GitHub Pages Policy (`docs/PRIVACY-EN.md`, `docs/PRIVACY-VI.md`, `docs/privacy/index.html`, `docs/index.html`, `docs/uninstall/`)**: Updated both Markdown privacy policies to document `chrome.storage.local` + best-effort `chrome.storage.sync` profile mirroring accurately, published a standalone zero-tracker bilingual HTML page at `docs/privacy/index.html` (`https://moments2505.github.io/better-visual-youtube/privacy/`), and updated `docs/uninstall/survey.js` to link directly to it.
- **Personal Edge Defaults Applied Out of the Box (`src/shared/settings.js`, `default-settings.json`)**: Updated fresh-install `DEFAULT_SETTINGS` with the curated profile (`accent: "#2dd4bf"`, `blur: 8`, `opacity: sliderToOpacity(8)`, `radius: 18`, `highlight: 0.25`, `optics.lensPx: 213`, `ambientLight`: `detectBarSize: true`, `modes.shorts: true`, `energySaver: false`, `brightness: 1.35`, `vibrance: 1.3`, `videoShadow: 55`, `flickerReduction: 55`, `fpsLimit: 15`, `daylightBackground.enabled: true`, `immersiveCinema: true`, `zenWatch: true`, `respectReducedMotion: false`), while keeping `daylightBackground.liveWeather: false` and `London, United Kingdom` as the safe international default for Chrome Web Store review.
- **Chrome Web Store Submission Kit (`docs/store/CHROME-WEB-STORE-LISTING.md`)**: Added ready-to-paste English & Vietnamese Store Listing descriptions, Single Purpose statement, exact permission justifications, data usage disclosures, reviewer testing steps, and asset dimensions checklist (`1280×800` screenshots + `440×280` 24-bit RGB no-alpha promo tile + `Better-visual-Youtube-0.7.2.zip`).

---

Better Visual for YouTube 0.7.2 cập nhật tên gọi chuẩn quy định nhãn hiệu Chrome Web Store, áp dụng bộ cài đặt tinh chỉnh cá nhân làm mặc định mới ngay khi cài đặt, đồng bộ Chính sách quyền riêng tư với `chrome.storage.sync`, dọn bỏ liên kết Google Form của upstream và bổ sung trọn bộ tài liệu nộp Chrome Web Store.

## Điểm mới chính

- **Đổi tên thương hiệu & Dọn liên kết Upstream (`manifest.json`, `_locales/*/messages.json`, `src/popup/popup.html`, `src/background/service-worker.js`, `vendor/ambient/content-main.js`)**: Đổi tên hiển thị từ *Better visual Youtube* sang **Better Visual for YouTube** (`short_name: "Better Visual"`) đúng quy chuẩn Chrome Web Store, đồng thời thay hàm `getFeedbackFormLink()` trỏ tới Google Form cũ thành đường dẫn GitHub Issues sạch sẽ của dự án.
- **Đồng bộ Chính sách Quyền riêng tư & Trang Privacy GitHub Pages (`docs/PRIVACY-EN.md`, `docs/PRIVACY-VI.md`, `docs/privacy/index.html`, `docs/index.html`, `docs/uninstall/`)**: Cập nhật chính sách EN/VI phản ánh đúng cơ chế lưu `chrome.storage.local` kèm sao lưu `chrome.storage.sync` qua tài khoản trình duyệt, tạo trang HTML tĩnh song ngữ `docs/privacy/index.html` (`https://moments2505.github.io/better-visual-youtube/privacy/`) không bộ theo dõi/CSP chặt chẽ và trỏ liên kết ở trang góp ý gỡ cài đặt về đúng URL này.

- **Bộ tài liệu chuẩn bị gửi Chrome Web Store (`docs/store/CHROME-WEB-STORE-LISTING.md`)**: Soạn sẵn phần mô tả Store EN/VI, Single Purpose, giải trình từng quyền (`storage`, `www.youtube.com`, Open-Meteo tùy chọn), khai báo Data Usage, hướng dẫn reviewer kiểm thử và danh mục ảnh `1280×800` + promo tile `440×280` 24-bit không alpha cùng gói `Better-visual-Youtube-0.7.2.zip`.
