# 0.4.57 — Stable hover between watch panels

Hover selection for video details, comments and recommendations now uses each
panel's original layout rectangle. A magnified panel can no longer capture the
pointer in the neighbouring panel's original area. One panel is selected at a
time, and the newly selected panel paints above panels that are still shrinking.

Pointer events are coalesced into one animation-frame callback, with at most three
panel geometry reads. Remaining in the same panel does not restart its animation.
The controller suspends during normal/theater transitions and releases its state,
listeners, timers and observers when disabled or during navigation. Native clicks,
scrolling, focus indicators and player input remain unchanged.

Validation includes regression cases for overlapping transformed rectangles,
rapid reversal, stale callbacks, keyboard focus, navigation and switch changes.
Offline CSS cascade checks cover the active/departing layer order. Browser-rendered
animation and FPS still need confirmation; the available browser connection was
disabled during this change.
