# Better Visual for YouTube v0.8.1

## What Changed

### Smooth Watch-Page Hover Across Description & Comments
- **Root-cause fix for `:has(...)` style-invalidation storms**: When the pointer enters YouTube's `#description` region, YouTube inserts interactive formatting nodes inside `yt-attributed-string` interleaved with synchronous style reads. Global and deep `:has(...)` rules across `chrome-surface.css`, `opacity-ceiling.css`, `liquid-components.css`, `daylight-integration.css`, `glass-optics.css`, `hover-refinement.css`, and `description-motion.css` previously amplified those 12 `UpdateLayoutTree` reads into `159.5ms` (`444–492` elements). Replacing them with lightweight root/panel state attributes (`data-ylg-frosted-glass`, `data-ylg-fullscreen`, `data-ylg-desc-expanded`) and class selectors cut `UpdateLayoutTree` total time to `21.12ms` (`1–50` elements).
- **Eliminated heavy panel filter & mask passes (`interaction-performance.css`)**:
  - Disabled the full-panel `#ylg-optics-aberration` SVG filter on `.ylg-glass[data-ylg-level="panel"]::before`.
  - Replaced `.ylg-glass[data-ylg-level="panel"]::after` bottom-38% `mask-image` compositing pass with an alpha-faded `linear-gradient`.
  - Neutralized expensive vendor ambient `drop-shadow` filters on `#description-inline-expander`, `#info-container`, `#upload-info`, watch action/comment buttons, and `ytd-comments`.
  - Added `contain: layout style !important` on Watch metadata and comments panels so hover mutations stay locally contained.
- **Zero-churn panel hover controller (`panel-hover.js`) & scoped hover optics (`glass-optics.css`)**:
  - Added dirty-flagged bounding-box caching (invalidated on scroll, resize, click, transform transition end, and navigation) with a steady-state zero-rAF fast path.
  - Fixed bottom scaled-overhang hit-testing continuity without dead `data-ylg-panel-side` mutations on `<html>`.
  - Scoped `.ylg-glass:hover` / `:focus-within` rules out of controller-managed Watch panels (`[data-ylg-panel-controller="on"]`).

## Verification
- Automated regression suite (`node scripts/check.js`): **28/28 suites passing**.
- Live muted headless Edge (`1440×900`, `Intel(R) Arc(TM) Graphics`) before vs. after measurements:
  - Lower 50% description interior: `p50 8.3ms / p95 8.4ms / max 8.9ms`, `0` frames > 33ms, `0` long tasks.
  - Bottom edge (`95%–104%`): `max 16.7ms` (down from `100ms`), `0` long tasks (down from `4`).
  - Bottom 50% + overhang sweep: `p50 8.3ms / p95 8.5ms / max 25ms`, `0` long tasks (down from `175ms` / `184ms` long task).
  - Continuous crossings (`ytd-comments` ↔ `ytd-watch-metadata`, 40 sweeps, default `zenWatch: true`): `p95 25ms / p99 33.4ms / max 41.7ms`, `0` long tasks (down from `p95 150ms / p99 208.3ms / max 258.3ms`, `40` long tasks up to `261ms`).

# Better Visual for YouTube v0.8.1 (Tiếng Việt)

## Điểm mới chính

### Rê chuột mượt trên toàn bộ khung Mô tả & giữa Bình luận – Mô tả video
- **Khắc phục triệt để bão tính toán lại style từ `:has(...)`**: Khi trỏ chuột đi vào vùng `#description` (nửa dưới khung mô tả), YouTube chèn thêm hàng loạt node vào `yt-attributed-string` xen kẽ các lần đọc layout đồng bộ. Các rule `:has(...)` phạm vi toàn trang trước đây trong `chrome-surface.css`, `opacity-ceiling.css`, `liquid-components.css`, `daylight-integration.css`, `glass-optics.css`, `hover-refinement.css` và `description-motion.css` khiến 12 lượt `UpdateLayoutTree` phình lên `159.5ms` (`444–492` phần tử). Việc thay bằng attribute trạng thái gọn nhẹ (`data-ylg-frosted-glass`, `data-ylg-fullscreen`, `data-ylg-desc-expanded`) và selector class trực tiếp giúp giảm tổng `UpdateLayoutTree` xuống còn `21.12ms` (`1–50` phần tử).
- **Loại bỏ các lớp filter & mask nặng trên panel lớn (`interaction-performance.css`)**:
  - Tắt bộ lọc SVG `#ylg-optics-aberration` kích thước lớn trên `::before` của panel trang Xem.
  - Thay `mask-image` 38% vùng đáy `::after` (vốn đè trực tiếp lên `#description`) bằng `linear-gradient` chuyển alpha thuần túy.
  - Triệt tiêu các `filter: drop-shadow(...)` tốn GPU từ vendor ambient trên `#description-inline-expander`, `#info-container`, `#upload-info`, các nút hành động và `ytd-comments`.
  - Cô lập phạm vi layout/style của khung mô tả và bình luận bằng `contain: layout style !important`.
- **Tối ưu controller hover panel (`panel-hover.js`) & cô lập rule `:hover` (`glass-optics.css`)**:
  - Cache tọa độ bounding-box theo cờ bẩn (chỉ làm mới khi cuộn, đổi kích thước, click, kết thúc transition hoặc điều hướng) kèm nhánh fast-path không cần rAF khi ổn định.
  - Giữ trạng thái hover liên tục ở phần rìa đáy phóng to mà không ghi attribute thừa `data-ylg-panel-side` lên `<html>`.
  - Tách rule `:hover` / `:focus-within` trong `glass-optics.css` khỏi các panel đang do controller quản lý (`[data-ylg-panel-controller="on"]`).
