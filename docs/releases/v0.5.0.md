# 0.5.0 — Official release / Bản chính thức

## English

- **Quick Style Profiles & Portable Settings:** switch instantly between *Crystal Clear*, *Tahoe Frosted*, *Cinema Glow* and *Eco Minimal*, sync preferences across signed-in browsers via `chrome.storage.sync`, or back up and restore configurations using **Export / Import** JSON.
- **Native Bilingual Interface (`en` / `vi`):** full Chrome Extension `_locales` localization with automatic language detection and zero horizontal overflow in the popup.
- **Native MV3 `"world": "MAIN"` & 70% Smaller Package (~309 KB):** eliminated cross-origin `<script>` / `<link>` / `import()` console errors on YouTube, removed `web_accessible_resources` fingerprinting surface, stripped dead telemetry code, and replaced 753 KB static debanding PNGs with cached procedural `<canvas>` grain.
- **CSS `@layer` Architecture & Visual Refinements:** seamless masthead-to-sidebar glass continuity at `y = 56px` under Time-of-day sky backgrounds, sharper dark-mode secondary metadata over bright Ambient Light, balanced fresh-install defaults (`Auto` theme, `14px` blur, `37%` opacity), and clean exclusion of `/embed/*`, `/live_chat*` and `/tv*` frames.

**Download:** choose **Better-visual-Youtube-0.5.0.zip** from the release assets. Extract it, enable Developer mode in `edge://extensions` or `chrome://extensions`, then use **Load unpacked** and choose the folder containing `manifest.json`.

**Updating:** replace the files in your existing extension folder with the extracted ZIP contents, click **Reload** on the extensions page, then reload all open YouTube tabs. Keep the existing installation to retain saved preferences. This release uses the same permissions as the previous version.

## Tiếng Việt

- **Cấu hình nhanh & Sao lưu cài đặt:** chuyển nhanh chỉ với 1 chạm giữa *Trong suốt pha lê*, *Kính mờ Tahoe*, *Rạp phim rực rỡ* và *Tiết kiệm tối giản*, tự động đồng bộ qua `chrome.storage.sync`, hoặc sao lưu / khôi phục cài đặt bằng nút **Xuất / Nhập** JSON.
- **Giao diện song ngữ Anh / Việt gốc (`_locales`):** tự động hiển thị ngôn ngữ theo trình duyệt, bố cục gọn gàng không tràn thanh cuộn ngang.
- **Chuẩn MV3 `"world": "MAIN"` & Giảm 70% dung lượng gói (~309 KB):** triệt tiêu hoàn toàn các lỗi console cross-origin trên YouTube, gỡ bỏ `web_accessible_resources`, dọn sạch mã telemetry thừa và thay thế 753 KB ảnh nhiễu PNG bằng nhiễu procedural `<canvas>` có bộ nhớ đệm.
- **Kiến trúc CSS `@layer` & Tinh chỉnh hiển thị:** nối liền mạch lớp kính giữa thanh đầu trang và thanh bên ở `y = 56px` khi bật nền trời theo giờ, tăng độ sắc nét chữ phụ Dark Mode trên nền Ambient sáng, cân chỉnh bộ mặc định cài mới (`Auto`, độ mờ `14px`, độ chắn sáng `37%`) và loại trừ các trang nhúng `/embed/*`, `/live_chat*`, `/tv*`.

**Tải và cài:** chọn **Better-visual-Youtube-0.5.0.zip** trong tài sản đính kèm của release. Giải nén, bật Chế độ nhà phát triển tại `edge://extensions` hoặc `chrome://extensions`, rồi chọn **Tải tiện ích đã giải nén / Load unpacked** và thư mục chứa `manifest.json`.

**Cập nhật:** giải nén ZIP mới đè lên các tệp trong thư mục extension đang dùng, bấm **Reload / Tải lại** trên trang tiện ích rồi tải lại tất cả tab YouTube đang mở. Giữ bản cài hiện tại để giữ các lựa chọn đã lưu. Bản này giữ nguyên các quyền truy cập so với phiên bản trước.
