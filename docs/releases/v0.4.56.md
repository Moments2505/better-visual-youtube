# 0.4.56 — Wheel controls and hover refinements

- Scroll over a settings slider to adjust it in its normal steps. Wheel changes
  use the same normalization and save path as dragging. Disabled controls,
  browser zoom gestures and horizontal scrolling are left alone.
- **Hover effects** can be switched off independently of **Motion effects**.
  The preference is saved. Static glass optics, click feedback and layout
  transitions remain available.
- Video information, comments and recommendations share one 420ms transform
  curve in both directions. Shadows no longer animate on these large panels.
  Mouse-click focus no longer keeps an old panel magnified, and the departing
  panel keeps its stacking level until its transition completes.

Validation covers source regressions, wheel/persistence behaviour and offline CSS
cascade checks. Browser frame rate and the tester's machine have not been measured.
